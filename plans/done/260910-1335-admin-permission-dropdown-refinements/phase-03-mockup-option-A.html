Design Rationale

  • Full-width button: min-height 44px, easily tappable on mobile
  • Chevron indicator: Rotates on expand for visual feedback
  • Two-line label on customize: Base role on first line, "+ tuỳ chỉnh" on second (muted color)
  • Groups always in DOM: Collapsed via CSS (display:none). Allows `collect()` to find checkboxes.
  • Single delegation: Uses existing `onClick` handler (data-act="toggle-perms")
