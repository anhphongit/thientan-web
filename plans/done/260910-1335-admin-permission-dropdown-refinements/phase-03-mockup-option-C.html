Design Rationale

  • Two-line label: Base on line 1, customization state on line 2 (only when present)
  • Compact: 44px height (tight), no visible badges
  • Color coding: Orange "tuỳ chỉnh" text; amber background for unknown custom
  • Unicode chevron: ∨/∧ symbols instead of ▼ (slightly more elegant)
  • Space efficient: Minimal vertical space, dense information density
  • Accessible: aria-expanded, aria-controls, full 44px tap target
