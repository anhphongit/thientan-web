Mockup · Option D

Inline select + note as full-width row below

Same starting point as Option A (status select inline in .form-grid, mirroring qty/UOM/VAT), but per user feedback the status note is no longer collapsed behind an icon — it's now a normal, always-visible .field spanning the full row width, directly beneath the select. Best when note text is expected to sometimes run long (multi-word reasons, dates, names).

Annotation notes

  • Blank status (Dòng 2): select shows the placeholder option "— Chưa có —", dashed left-border, muted grey text — a real, selectable, empty-string option, never coerced to the first status key (draft). Its note field is also shown, empty, with an italic muted placeholder "Chưa có ghi chú trạng thái" — no status set does not block entering a note ahead of time.
  • Disabled (Dòng 3): user lacks change_status on this line — select AND note input both carry disabled, greyed via the existing .field input:disabled rule, current values still visible/read-only, plus the inline "Không có quyền đổi trạng thái" tag.
  • No toggle, no hidden state: every line always renders both the select and the note field — nothing to click to reveal. Removes the "does this line have a note?" guesswork Option A's icon introduced, at the cost of an extra field height on every single line, always.
  • 360px tradeoff (see frame below): this is the real risk of this variant — every line now permanently carries a 7th stacked field (vs. Option A's conditional note). Compare Dòng 2/3 here (short empty/placeholder rows still cost full field height) against the same rows in option-a, where an empty note simply doesn't render at all.

Tradeoff summary vs Option A

Removes Option A's icon-toggle guesswork — the note is always right there, editable, no click required, and has full row width for longer text. The cost: every line is now permanently one field taller than Option A (which only grows when a note exists). At 1280px (3-col grid) this barely registers. At 360px (1-col) it's the most honest measure of the cost — even Dòng 2/3 with an empty/read-only note still pay the full field height, so a 5-line order now scrolls noticeably longer than the same order in Option A.
