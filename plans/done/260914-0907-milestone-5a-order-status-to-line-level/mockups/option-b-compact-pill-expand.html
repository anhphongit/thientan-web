Mockup · Option B

Compact pill, expand on click

Collapsed state adds almost no row height — the status lives as a .status-pill badge right next to "Dòng N". Tapping/clicking it swaps in the select + note fields inline. Best density at 360px; costs an extra interaction step to actually change a status.

Annotation notes

  • Collapsed vs expanded (Dòng 1a / 1b): same line shown twice — 1a is the default "closed" pill, 1b shows what appears after a tap (select + status-note input, small "sau khi bấm" demo tag). No real JS in this mockup; both states are just rendered side by side for review.
  • Blank status (Dòng 2): a dashed, colourless "Chưa có trạng thái" badge — deliberately NOT a .status-pill variant, so it can't visually default to draft's look.
  • Disabled (Dòng 3): pill renders with its real value ("Chờ hàng về") but non-interactive — no cursor, no click handler, 60% opacity, plus the same permission tag used in the other mocks for consistency.
  • 360px density: collapsed rows stay one line tall even with 6 other fields already in the grid — this is the strongest candidate for the mobile lines table.

Tradeoff summary

Best row density at 360px — collapsed state costs almost nothing (one pill next to "Dòng N"). Tradeoff: changing status is now two steps (tap pill → edit select/note) instead of one, and the "what does clicking do" affordance relies purely on the pill looking tappable (no chevron/pencil in this draft).
