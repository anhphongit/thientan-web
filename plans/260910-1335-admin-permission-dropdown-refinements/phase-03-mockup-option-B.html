Design Rationale

  • Single-line label: Role name on left, optional amber badge on right (minimal)
  • Badge styling: Warm amber background, uppercase "tuỳ chỉnh" (matches warning palette)
  • Quick scan: Users see badge immediately without expanding
  • Space efficient: All info on one line; less vertical height than multi-line variant
  • Mobile friendly: 44px min height, full width button
